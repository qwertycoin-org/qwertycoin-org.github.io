Qwertycoinについて

プライバシー。 QWCを搭載。

QWC をプライベートな支払いに使用したり、マイニングを通じてコンピューティング能力を提供したり、サービスノードとしてネットワークをサポートしたりできます。

オープンネットワーク

QWC Coreネットワーク

オープンネットワーク上でQWCを送受信します。独立したノードがトランザクションを検証し、ブロックチェーンを維持します。

プライバシー

組み込まれたプライバシー

QWC はプライバシー技術を使用して取引の詳細を保護します。そのオープン ソース コードにより、誰でもネットワークがどのように機能するかを調べることができます。

PoW

RandomX Proof of Work（プルーフ・オブ・ワーク）

RandomX マイナーは新しいブロックを生成し、ブロックチェーンを保護します。互換性のあるマイニング ソフトウェアを使用すれば誰でも参加できます。

EPoSe

実績のあるサービスに対する報酬

サービスノードはネットワーク サービスを提供します。有効なアテステーションによって資格が確立され、EPoSe プロトコルによって報酬のローテーションが決定されます。

ネットワークサービス

サービスノード

サービスノードはネットワークをサポートし、EPoSe に参加します。 QWC ステーキングは必要ありません。ブロックの生産は依然として RandomX マイナーの仕事です。

EPoSe

サービスを証明します。 QWCを獲得します。

EPoSe は、実績のあるネットワーク サービスに対して登録されたサービスノードに報酬を与えます。このプロトコルは、ブロックチェーンに記録された有効なアテステーションを評価し、どのノードが報酬ローテーションの対象となるかを決定します。

02

サービスを確認します。

プロトコルで選択された検証者はサービスの応答をチェックし、署名されたアテステーションを送信します。

EPoSeの原点

ありがとう、ゼキュート。

Xecute は、オリジナルの EPoSe ビジョンを開発し、Qwertycoin サービス層のホワイトペーパーに貢献しました。この取り組みは、有用なネットワーク サービスに報酬を与えるための基礎を築きました。

報酬はプロトコルに従います。 すべての完全なノードは、報酬の資格とブロックチェーンからの受信者の選択を検証できます。補助金の割り当て: 90% マイニング / 10% EPoSe サービス報酬。取引手数料はマイナーに残ります。

サービスノード

ネットワークをサポートします。サービスを通じて収益を得る。

すべてのフルノードがブロックチェーンデータを検証して中継します。登録されたサービスノードも EPoSe に参加し、サービス報酬の資格を得ることができます。

通常ノードサービスノード
ブロックとトランザクションを検証し、チェーンを同期し、データを中継します。同じノード機能を実行し、登録された EPoSe サービスを提供します。
通常のノードを単独で操作しても、EPoSe 報酬は獲得できません。有効なサービス証明書を通じてサービス特典の資格を得ることができます。

公式Qwertycoinプール

数分でマイニングを開始できます。

公式プールは、透明な PPLNS 会計、ライブ統計、自動支払いを提供します。 QWC の支払いアドレスはプール口座です。プールがウォレット キーを要求することはありません。

  • アルゴリズム: RandomX (rx/0)
  • 登録なし: QWC 支払いアドレスを使用してください
  • ライブハッシュレート、ワーカー、ブロック、支払い統計
  • 各支払いアカウントは、独自の支払いに対して実際のネットワーク料金を支払います。
公式プールをオープン XMRigコマンドの作成 プールマイニングガイドを読む

2 つの別々の報酬レイヤー

QWCプロトコル 90% マイニング / 10% EPoSe

ブロック補助金は 90% がマイニングに、10% が EPoSe サービス報酬に分割されます。取引手数料はマイナーに残ります。

公式プール 95% マイナー / 5% プール

公式プールを通じて分配されるマイニング報酬から、5% が Qwertycoin の開発とプール運営に資金を提供します。各アカウントの支払い取引手数料の前に、正確に 95% が参加マイナーに割り当てられます。

EPoSe よくある質問

新しいオペレーター向けの短い回答。

Qwertycoinとは何ですか？

Qwertycoin (QWC) は、RandomX プルーフ・オブ・ワーク・マイニングと実績のあるネットワーク・サービスに対する EPoSe 報酬を備えたプライバシー重視の暗号通貨です。

Web Walletの使い方は？

公式 Web Wallet を開き、そこでウォレットを作成または復元し、その安全手順に従ってください。メイン Web サイトはウォレット キーを処理しません。

古いQWCウォレットは使用できますか?

いいえ、現在の QWC ネットワークは以前のチェーンとは別のものです。従来のウォレット ソフトウェアとブロックチェーン データは、このネットワークと互換性がありません。

EPoSe はマイニングを置き換えますか?

いいえ、RandomX マイナーはブロックを生成し、ブロックチェーンを保護します。 EPoSe は、実績のあるネットワーク サービスに対する特典を追加します。

エポックとは何ですか?

エポックは、EPoSe サービス アクティビティを評価するために使用されるブロック期間です。現在、これは 720 ブロックに及び、ターゲット ブロック間隔で約 24 時間になります。

資格があるとはどういう意味ですか？

適格なサービスノードは、関連するエポックにおける有効な認証に関するプロトコルの要件を満たしており、サービス報酬の選択の対象となります。技術的な定足数は少なくとも ceil (2 x 実際の委員会のサイズ / 3) です。

資格や報酬は誰が決めるのですか？

EPoSe プロトコル。すべての完全なノードは、資格と報酬の選択を検証するために、有効なオンチェーン登録と証明書に同じルールを適用します。

サービスノードはQWCをステーキングする必要がありますか?

いいえ。参加するには、QWC をステークとしてロックするのではなく、EPoSe の登録と必要なサービス証明が必要です。

1 人のオペレーターが複数のサービスノードを実行できますか?

はい。各サービスノードには独自の有効な登録が必要であり、プロトコルのサービス要件を満たしている必要があります。参加証明により、安価な ID 作成が困難になります。

EPoSe がプルーフ オブ ステークではないのはなぜですか?

EPoSe は、ロックされた賭け金ではなく、実績のあるサービスに報酬を与えます。サービスノードは他のフル ノードと同様にブロックチェーン データを検証し、一方、RandomX マイナーはプルーフ オブ ワーク ブロックの生成を実行します。

歴史

2018 年以来。次の章を構築中。

Qwertycoin は 2018 年に始まりました。今日のネットワークは、RandomX と EPoSe の歴史に基づいて構築されています。

2018オリジナルのQWCコミュニティチェーン
2026QWC と RandomX および EPoSe ネットワーク
2018

Qwertycoin発売

QWC は、初期のウォレット、エクスプローラー、コミュニティ、インフラストラクチャの取り組みにより、CryptoNote ベースのコミュニティ プライバシー コインとして始まりました。

2019–2023

EPoW および EPoSe の研究開発

2019 年から 2023 年にかけて、このプロジェクトでは、ウォレット、ノード、インフラストラクチャと並行して、公正なマイニングとネットワーク サービスの報酬を検討しました。 Xecute の EPoSe の取り組みは、有用なネットワーク サービスに報酬を与えるというビジョンを形作りました。

後で

トークンフェーズ

トークンフェーズは Qwertycoin の歴史の一部であり、今日の QWC ネットワークとは別のものです。

2026

Qwertycoinネットワーク

Qwertycoin は、プライベート支払い、RandomX マイニング、EPoSe サービス報酬を備えた新しいネットワークを開始します。

現在の QWC ネットワークは、以前のチェーンとは別のものです。従来のウォレット ソフトウェアとブロックチェーン データは、このネットワークと互換性がありません。

開発者
