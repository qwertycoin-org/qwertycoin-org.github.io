# Legacy Website Audit

This audit records what was kept, rewritten, removed, or treated as historical
material during the Qwertycoin website relaunch.

## Matrix

| Area | Decision | Notes |
| --- | --- | --- |
| Qwertycoin name and QWC ticker | KEEP | Brand identity remains valid. |
| 2018 launch story | HISTORY ONLY | Retained in a short timeline, separated from QWC. |
| CryptoNote origin | HISTORY ONLY | Mentioned only as legacy origin, not current positioning. |
| CryptoNight / CryptoNight-Heavy | HISTORY ONLY | Replaced by RandomX in current mining and technology sections. |
| EPoW | HISTORY ONLY | Retained as historical experiment, not a current protocol claim. |
| Old EPoSe / Sentinel / Masternode model | REMOVE | Replaced with EPoSe v2, no central Sentinel reward authority. |
| Old wallet downloads | REMOVE | No current v2 release downloads are offered. |
| Old web wallet / myqwertycoin.com | REMOVE | Replaced with the current `wallet.qwertycoin.org` web wallet workbench link. |
| Old roadmap | REWRITE | Replaced with status-based v2 roadmap. |
| Old team | REMOVE | No current team names are shown until confirmed. |
| Voting platform | HISTORY ONLY | Not linked as current infrastructure. |
| Jobs | REMOVE | No current hiring flow exists. |
| Exchanges and price lists | REMOVE | QWC market support is not claimed. |
| Mining pools | VERIFY | No current pool list is published until v2 pools are verified. |
| Merchant lists | REMOVE | No current v2 merchant support is claimed. |
| Explorer / node map | REWRITE | New explorer link points to current QWC observer deployment. |
| Social links | VERIFY | GitHub, explorer, and X/Twitter are linked; dead legacy links omitted. |
| Releases | REMOVE | Build-from-source only until signed v2 releases exist. |
| Absolute privacy claims | REMOVE | No guarantees such as "totally untraceable" are used. |
| Remote CSS/JS CDNs | REMOVE | New site uses local assets and no third-party scripts. |

## Source Priority

Current technical facts come from the QWC core branch and live v2 explorer
observer endpoints. Legacy website content is never treated as current protocol
truth when it conflicts with the v2 core.
