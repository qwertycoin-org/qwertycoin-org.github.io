# Classic Layout Draft

This branch provides a second visual direction for the Qwertycoin website.

The goal is to keep the familiar shape of the historical qwertycoin.org layout while retaining the corrected QWC content model:

- full-screen photographic hero
- transparent header over the hero
- compact headline, clearer call-to-action hierarchy, and live network pulse
- amber QWC primary action color with blue as the technical secondary accent
- light section rhythm with centered headings
- icon-led feature and wallet cards
- current QWC facts only

The draft intentionally does not restore legacy download links, old exchange lists, old wallet links, CryptoNight claims, masternode language, or hard privacy guarantees. Those remain removed or history-only because Qwertycoin is a new chain with RandomX and EPoSe v2.

Assets reused from the historical website:

- `assets/classic/hero-bg.jpg`
- `assets/classic/logo.png`
- selected local SVG illustrations for feature cards

No third-party scripts, external fonts, analytics, ads, or remote social widgets are introduced.
