# Qwertycoin brand kit

Reusable Qwertycoin logos, wordmarks, call-to-action graphics, diagrams and section artwork.

## Stable public paths

- PNG: `https://qwertycoin.org/assets/brand-kit/png/<filename>.png`
- SVG: `https://qwertycoin.org/assets/brand-kit/svg/<filename>.svg`

Example:

```text
https://qwertycoin.org/assets/brand-kit/png/qwc-logo-2048.png
```

The PNG files are raster exports for social posts, announcements and applications that do not support SVG. Prefer the SVG versions for websites and documents when available.
