Desktop wallet

A graphical app to create or restore a wallet, send and receive QWC, and connect to the network.

GUI

Windows

x86_64 · unsigned

Download Setup Alternative: portable ZIP
  1. Download the Setup EXE and verify its checksum before opening it.
  2. Run Setup and follow the installation steps. Then open Qwertycoin from the Start menu.
  3. Using the portable ZIP? Extract the entire archive first, then launch qwertycoin-gui.exe from the extracted folder.

macOS

Apple Silicon · macOS 15+ · not Intel

Download DMG Alternative: TAR.GZ
  1. Download the DMG for an Apple Silicon Mac and verify its checksum.
  2. Open the DMG and drag Qwertycoin into Applications. Eject the disk image, then open the app from Applications.
  3. The TAR.GZ alternative contains the app bundle: extract it and move the app into Applications.

Linux

x86_64 · GLIBC 2.35 build target

Download TAR.GZ
  1. Download the TAR.GZ archive and verify its checksum.
  2. Extract the complete archive with your archive manager. Keep the bundled files together.
  3. Open a terminal in the extracted application folder and run ./qwertycoin-gui.

SHA-256

Check your download

Before opening a package, download SHA256SUMS for the same product and release. Replace PACKAGE below with the downloaded filename and compare the full hash with that file’s entry.

Windows · PowerShell
Get-FileHash -Algorithm SHA256 .\PACKAGE
Linux · Terminal
sha256sum ./PACKAGE
macOS · Terminal
shasum -a 256 ./PACKAGE

The links on this page move to newer releases. If a release changes between downloads, use the versioned GitHub release matching your package to get its checksum. A matching SHA-256 verifies the bytes, not the publisher’s identity.

About security prompts

Windows and Linux packages are unsigned. macOS packages are ad-hoc signed and not notarized, so your system may display a warning. Check the source and checksum first; do not disable your antivirus. If macOS blocks a verified app, check System Settings → Privacy & Security after your first launch attempt.

Already have a wallet?

Back up your wallet and recovery phrase before updating. Never share your recovery phrase. These downloads are for the current QWC network; legacy wallet software and legacy balances are not compatible.
